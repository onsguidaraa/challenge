# Learnova frontend

A self-contained frontend prototype for an AI-powered personalized learning platform.

## Run locally

Open `index.html` directly in a browser, or serve this folder with any static server:

```bash
npx serve .
```

The prototype uses local mock data and vanilla JavaScript so it runs without a backend or build step. It includes responsive navigation and interactive dashboard, learning profile, learning space, planner, practice, mistakes, growth, AI companion, roadmap, community, and achievements views.
